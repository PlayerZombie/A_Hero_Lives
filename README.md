## 功能

- 🖱️ **拖拽收集** — 把网页上的图片拖进悬浮框即可收集
- 📋 **一键复制** — 点击复制按钮，所有图片写入剪贴板，直接粘贴到QQ/微信
- 🗑️ **一键清空** — 清除所有已收集的图片
- 🔄 **跨Tab同步** — 所有浏览器标签页共享同一份图片数据
- 📎 **来源标注** — 每张图片显示来源网站
- 🔽 **折叠预览** — 预览图默认折叠，点击展开
- 📌 **可拖动** — 悬浮框可自由拖动位置
- ➖ **最小化** — 可最小化悬浮框

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目文件夹
4. 打开任意网页，右上角出现悬浮框

## 使用

1. 在网页上拖拽图片到悬浮框
2. 点击「📋 复制全部」
3. 在聊天窗口粘贴（Ctrl+V）
4. 成为英雄 🎉
